# NoteHub (Next.js)

Application for creating, searching and deleting notes, built with Next.js App Router, TanStack Query, Formik and Yup.

## Run locally

1. Create a `.env.local` file in the project root:

   ```env
   NEXT_PUBLIC_NOTEHUB_TOKEN=your_token_here
   ```

2. Install dependencies and start the dev server:

   ```bash
   npm install
   npm run dev
   ```
